---
name: Playtest Facilitation
description: Preparar y conducir una prueba de juego con el usuario, recoger feedback creativo y convertirlo en decisiones.
---

# Cuándo usarla

Cuando hay una build jugable o un experimento listo para que el usuario lo pruebe.

# Antes

- Asegurar que arranca con un comando.
- Preparar una lista de 3-5 cosas que probar.
- Definir qué decisiones se quieren validar.
- Evitar preguntas técnicas si el usuario solo necesita jugar.
- Tener capturas o una forma de registrar observaciones.

# Guion

1. “Abre esta URL.”
2. “Prueba esto durante 5 minutos.”
3. “Cuéntame qué has sentido, sin pensar en cómo está hecho.”
4. Preguntar por:
   - claridad;
   - ritmo;
   - control;
   - cámara;
   - dificultad;
   - ganas de repetir.
5. No defender la implementación.
6. Separar bug de decisión creativa.

# Después

- Registrar feedback en el requisito o experimento.
- Convertir bugs en tareas.
- Convertir decisiones creativas en requisitos o experimentos.
- No crear tareas de mejoras ambiguas sin criterio.

# Checklist

- [ ] Build reproducible.
- [ ] Instrucciones de prueba claras.
- [ ] Preguntas de experiencia, no de código.
- [ ] Feedback registrado.
- [ ] Decisiones creativas del usuario registradas.
- [ ] Bugs convertidos en tareas.
