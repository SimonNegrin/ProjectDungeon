Pixelify Sans
=============

Autor/proyecto: The Pixelify Sans Project Authors
Origen: https://github.com/eifetx/Pixelify-Sans
Licencia: SIL Open Font License, Version 1.1 (ver OFL.txt en este mismo directorio)

Este directorio incluye únicamente la fuente variable
PixelifySans-VariableFont_wght.ttf, que cubre los pesos 400–700. No se incluyen
las fuentes estáticas del proyecto original: la variable cubre todos los pesos
que usa la interfaz.

Los archivos de la fuente se distribuyen sin modificaciones.
