# 32rogues

Arte placeholder del primer prototipo de ProyectDungeon.

- Autor: Seth Boyles (Seth)
- Fuente: https://sethbb.itch.io/32rogues
- Versión: 0.5.0
- Licencia: ver [LICENSE.txt](LICENSE.txt)

## Uso en este proyecto

- `tiles.png`: muros y suelos de la sala.
- `rogues.png`: sprites de personajes; el jugador usa el caballero.
- `monsters.png`: sprites de monstruos; el enemigo usa el goblin.
- Los archivos `.txt` documentan las coordenadas de los sprites originales.

El pack se usa como arte del juego, no para entrenar modelos de IA ni para
redistribuirlo por separado. Crédito: **Arte: 32rogues de Seth Boyles**.
